# img-mini-tools
img-mini-tools is a lightweight CLI tool for performing simple image edits

## USAGE AND OPTIONS
```bash
img-mini-tools INPUT OUTPUT [OPTIONS...]
```
### General Options
```bash
-h, --help            show this help message and exit
--re-write            Rewrite the output image if it exists
--crop                Returns a minimum rectangle containing all pixels whose alpha > 0
--re-size WIDTH HEIGHT
											resize the image to the specified dimensions
--aspect-ratio WIDTH:HEIGHT
											Resize de the image to a specific aspect ratio without distorting it.
```
